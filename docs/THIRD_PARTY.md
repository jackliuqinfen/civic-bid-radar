# 第三方组件与数据

| 组件 | 范围 | 处理 |
| --- | --- | --- |
| Better Auth 1.7.27 | 登录、会话和数据库适配 | npm 安装，MIT，版本与完整性锁定在 `runtime/selfhost/package-lock.json` |
| 传递 npm 依赖 | 锁文件列出 21 个安装包，包含直接依赖 | 按锁文件许可证字段盘点为 MIT。候选库只发布依赖清单，依赖由 npm 下载 |
| Node.js 与 SQLite | 运行环境，由安装者提供 | 候选库仅含应用源码，安装命令复用 Node 内置 SQLite |
| Requests、Beautiful Soup、lxml | 可选 Python 公告抓取 | 公共发布前锁定版本并核查依赖与许可 |
| RapidOCR、Tesseract、Poppler | 可选本地附件及证件提取 | 需要单独核对推理模型、词典、训练权重和工具分发许可。候选库不内置这些二进制 |
| 盐城公开栏目清单 | 网站入口、栏目范围和少量公开样本地址 | 候选包只保留适配需要的公开入口元数据。公开发布前核查来源条款、版权和数据允许用途 |
